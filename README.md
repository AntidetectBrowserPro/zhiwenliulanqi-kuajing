# 如何用指纹浏览器管理多家店铺？

两家店都卖同一款商品，客服发来订单号时，两个窗口的标题又都叫「订单管理」。在 **「指纹浏览器」** 里，可以按店铺命名环境，从工作台直接定位到已经打开的那家店。先让接班人用店名找回一笔测试订单，再决定这套组织方式是否适合团队。

## 把一次查单拆成三个动作

| 动作 | 关注点 | 验收方法 |
| --- | --- | --- |
| 找店 | 店名、地区和岗位能否一眼认清 | 新同事按口头给出的店名找到目标行 |
| 回到订单页 | 已打开的窗口能否找回 | 另开一个店铺后再回到原来的后台 |
| 交接 | 新同事能访问哪家店 | 用其自己的账号核对可见店铺与网站角色 |

指纹浏览器可为每家店建环境，再按品牌或项目分组。电脑工作台能按名称搜索，已经打开的环境可点「定位」。命名时可用「青山－德国店－售后」，比「运营 03」多给接班人两条辨认线索。[环境分组教程](https://zwbrowser.com/help/desktop/groups/)

## 比较面向店铺的产品

紫鸟超级浏览器从跨境店铺运营切入。看演示时，让管理员按店铺和岗位分别分配访问范围，之后从客服账号打开店铺，观察实际可做哪些事。[紫鸟官网](https://www.ziniao.com/)

![紫鸟超级浏览器产品展示](https://github.com/user-attachments/assets/94d36ce4-1ffb-417d-9dd0-e4809e65da9e)

最后单独验证交班后的撤权。浏览器允许进入某个环境、店铺后台允许退款，是两个权限层次。拿一笔测试订单检查前者和后者分别由谁管理，再决定是否符合实际分工。
